# Changelog

Generado con `npm run changelog` (scripts/changelog.mjs) desde el historial de git y 245 PR fusionados en GitHub.

## Como regenerar

```bash
npm run changelog        # regenera este archivo completo
npm run test:changelog   # prueba de los limites de sprint
```

## Reglas de agrupacion

- Los commits se asignan al sprint por fecha de autor (ano 2026).
- Commits en los huecos entre sprints, o posteriores al ultimo sprint, van al sprint siguiente mas cercano (o al ultimo si ya paso).
- Commits anteriores al Sprint 1 (29/03) van a "Otros (previo al Sprint 1)".
- Se excluyen los commits de merge; el numero de PR se toma de "(#n)" o del merge del PR que contiene el commit.
- Tipos segun Conventional Commits; los demas van a "Otros".
